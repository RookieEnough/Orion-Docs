# Orion Docs

Documentation for the [Orion Store](https://github.com/RookieEnough/Orion-Store) — a transparent Android app store built around public releases and inspectable metadata.

## Contents

- [Architecture](architecture.md) — how the store client, data layer, and automation fit together
- [Community Engine](community_engine.md) — community systems and engagement
- [Security](security.md) — security model and practices
- [Trust Lifecycle](trust_lifecycle.md) — how trust is established and maintained across the ecosystem
- [Contributor Guide](contributor_guide.html) — how to contribute to the project

Each Markdown document has a matching `.html` rendering alongside it. `index.html` is the browsable landing page.
